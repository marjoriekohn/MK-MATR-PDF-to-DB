# Questionnaire layouts: page-by-page catalogue

Raw notes from reading every page of the 16 PDFs in `edge-case-pdfs/` (November 2026). The summary and proposals are in [questionnaire_layouts.md](questionnaire_layouts.md). Words in CAPITALS mark the edge case a note is about. Quotes are the printed wording.


## GNA (4 pp, scanned)
- p1-2 Q1 a–ag: "Please answer each question by marking Yes or No." ITEM rows (whole questions) x CHOICE cols (Yes/No). Runs across 2 columns of the page. -> a Group with the Instruction: whole questions, no lead-in.
- p2 Q3 children: INSTANCE rows (each living child; name column redacted) x MEASURE cols (#2 birth year, #3 sex, #4 relationship, #5 living with you Yes/No). Column headers numbered "#2 –". -> Grid sideways (each column a Question, variables Child 1..5). Lead-in "Please provide the following information for all of your living children (include ...)".
- p2 Q4 "Do you have more than five (5) children? O Yes" lone check box.
- p2 Q5 siblings: INSTANCE rows, only Sex (M/F) column left after redaction; Q6 lone box.
- p3 Q8 "Thinking back to the time in your life when you were smoking the most:" a–d each with DIFFERENT choices (timing, how often, difficulty, craving). SHARED LEAD-IN WITHOUT SHARED SCALE. Same Q11 "At the time ... drinking the most:" a choices, b write-in number.
- p3 Q12 "During the period that you were drinking the most, how often..." lead-in trails "..." and items finish it ("did you have six or more drinks on one occasion?"). ITEM x CHOICE, column headers "Monthly or less than monthly".
- p3 Q13 choices "No, never (Go to 15)", "Yes, only after the death..." -> qualifiers + skips.
- p3 Q14 "During the worst time:" setting lead-in, ITEM (whole questions) x CHOICE ("Yes, most of the time" / "Maybe or Somewhat" / "No").
- p3 Q9 write-in "cigarettes per day" unit + "(one pack equals 20 cigarettes)" definition inside the question.
- p4 Q15 "Step 1 ... Step 2 ..." ITEM rows (a–ao conditions, 2 page columns) x two COLUMN GROUPS: "Step 1: Yourself" {Have you had: lone Yes; If yes, age started: number yrs; Being treated now: lone Yes} and "Step 2: Family" {Has any biological family member had: lone Yes}. SUBJECT column groups with several MEASURES each, and a VARIABLE CONDITIONED ON ANOTHER VARIABLE OF THE SAME ROW ("If yes, age started").
- p4 Q16 write-in box; Q17 Yes/No then "If yes, write medications below. Please do not include vitamins..." write-in box (follow-up + instruction).
